# MDM vs Kimodo — Motion Gallery

Browsable gallery of generated motions from an experimental comparison of
MDM (Tevet et al., 2022) and NVIDIA Kimodo (Rempe et al., 2026):
text-to-motion quality, sampling diversity, keyframe in-betweening, and
root-path following.

**Live page:** https://anastasija42.github.io/diffusion-motions-gallery/

Contents: side-by-side skeleton animations (MDM | Kimodo) of representative
cases per experiment, with per-case metrics. Only **model outputs** are
visualized; no motion-capture dataset content is redistributed. Kimodo outputs
are produced with `Kimodo-SOMA-RP-v1.1` under the NVIDIA Open Model License;
MDM outputs with the public `humanml_trans_enc_512` checkpoint.
